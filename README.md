# BlackJack
  A simple BlackJack game with campaign mode, multiplayer mode, and quick play
  It contains a home page which has options to select Multiplayer, Campaign, or Quick Play.
  The home page is coded with index.html and style.css
  The campaign mode and quick play mode redirect to game.html only difference is what bankroll they load, since quick play loads the same bank roll each time while campaign mode saves your money amount. If you go broke you can reset campaign. 
  Campaign.css campaign.html and campaign.js purely control the page in between the homepage where you select campaign and game.html. This display shows which tables with which denominations you can play at. This is also where you reset your campaign.
